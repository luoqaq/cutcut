# AI 辅助剪辑：完整流程与宠物视频质量改进

调研日期：2026-10-23。面向本项目的生活记录／宠物实拍，兼顾抖音与小红书。本轮查资料和修订流程，没有重剪、安装工具或发布视频。

## 结论

网上有成体系的资料。实用的组合是：**AI 工作流说明负责划分自动化任务，专业后期资料负责声音与画面标准，作者公开项目负责可执行步骤。** 还不能据此认定有一套已验证能自动剪好本项目、同时稳定获得高播放的方案。

本项目优先补四项：动手前写风格卡；把原声与音乐纳入结构设计；逐镜校色后统一风格；把完整观看、实际试听与文件检测分别记录。现有剪映继续作为执行候选，不以购买新软件为前提。

## 适用于本项目的执行流程

以下是基于资料、用户反馈与现有素材制定的**项目方案**，不是平台算法规则，也未完成本项目效果实验。

```mermaid
flowchart LR
    A[内容简报与风格卡] --> B[素材与原声盘点]
    B --> C[故事及开头备选]
    C --> D[带临时音乐的粗剪]
    D --> E[精剪与节奏调整]
    E --> F[声音与色彩精修]
    F --> G[两平台包装]
    G --> H[完整视听审片与文件检查]
    H --> I[发布后复盘]
```

音乐方向和色彩参考在开剪前确定，精细混音与逐镜调色放在结构较稳定后；需要时可返回调整镜头，不机械要求先锁画面再碰音乐。

| 环节 | AI / 自动化负责什么 | 必须做的创作判断与交付 |
|---|---|---|
| 1. 内容与风格 | 根据素材主题整理参考，拆出可观察的节奏、声音、颜色与字幕特点 | 一句话看点；主情绪；参考链接及时间码；本条风格卡。每个参考只取明确方法，不直接照抄 |
| 2. 素材盘点 | 提取媒体信息、候选关键帧、转录与可疑问题，保留时间码 | 连续复看候选段前后文，记录动作、反应、关系及原声。标明哪些已看／已听，哪些仅抽帧或模型判断 |
| 3. 结构设计 | 给出有素材依据的主线、开头与镜头顺序备选 | 选一条真实成立的小故事；镜头表必须写源入出点、作用、字幕及声音，不用文案补造事件 |
| 4. 粗剪 | 组接、裁切、占位字幕，试放候选音乐 | 能判断看点、故事和大致情绪；音乐标为临时或候选，基础音量与衔接可听。不能只交技术正常的静音感预览 |
| 5. 精剪 | 批量调整、生成对照预览、定位重复段 | 逐切点看动作和反应是否完整；删掉重复信息；在关键处保留停顿。节奏由内容决定，不强制每几秒一切或逢拍必切 |
| 6. 声音 | 转录、适量降噪、音量关键帧及响度／峰值检测 | 听原声→确定保留段→比较音乐→设计进出和留白→混音。记录曲名、来源及适用范围；不同发布平台分别确认音乐使用条件 |
| 7. 色彩 | 辅助参考帧对比，初步匹配与批量应用 | 先确认素材色彩处理方式，再逐镜调整曝光、白平衡和对比；最后统一风格。以毛发、皮肤及场景连续性判断，避免一键加亮加暖代替校色 |
| 8. 包装 | 字幕校对、不同版式与封面备选 | 竖屏运动中主体不丢；字不挡表情、手部互动及关键信息；按目标平台当前界面检查遮挡，封面标题符合实际故事 |
| 9. 审片与复盘 | 完整解码、参数、静音／峰值检查；整理时间码反馈和发布数据 | 看导出文件完整视频、实际听混音，必要时以手机扬声器与耳机比较。创作问题写时间码与修改动作，不只打总分 |

## 风格如何变成可执行要求

“高级、治愈、有电影感”不足以指导剪辑。每条视频先填这张卡，参考对象可以是同题材，也可以只参考某条视频的声音或色彩。

| 字段 | 要写清楚什么 |
|---|---|
| 主情绪与看点 | 希望观众感到什么；素材中的哪个动作或关系支撑它 |
| 参考 | 约 2–3 条链接、具体时间码、分别借用什么；这些数量只是本项目工作安排 |
| 镜头与节奏 | 哪些动作必须看完整，哪里允许留白，哪里需要更紧；为什么切换视角 |
| 声音 | 原声主次、音乐情绪与音色、音乐何时进入／退出、哪里留安静或突出动作声 |
| 色彩 | 自然／偏暖等方向，保留哪些真实颜色；选择本素材中的一帧作为匹配基准 |
| 字幕与图形 | 字体、层级、位置、出现时机；是对白转写、情境评论还是说明文字 |
| 验证 | 用哪段预览比较、具体比较什么；实际完整看片／试听由谁完成、结果是什么 |

### 当前宠物素材可先比较的两个方向

下面是基于 v01 已选画面提出的创作假设。原片声音尚未完成听辨，不能先承诺有可用狗叫或清晰对话。

| 选择 | A：自然陪伴，建议先试 | B：轻喜剧 |
|---|---|---|
| 看点 | 把“陪上班”拍成真实的亲密日常 | 主人工作、宠物享受的轻微反差 |
| 剪法 | 留住摸摸、看人、趴下的反应；减少意义相同的重复镜头 | 动作与反应建立节奏，少量字幕接包袱；不靠密集转场制造热闹 |
| 声音 | 优先找可用原声；柔和、不过分抢旋律的音乐作陪衬 | 较轻巧的音乐，反应处尝试音乐让位或留白；音效有明确作用才加 |
| 色彩 | 先统一曝光和白平衡，再尝试轻微暖感；白毛与肤色自然 | 保持自然底色，可试更清晰的明暗层次；不直接提高全片饱和度 |
| 比较办法 | 先用相同片段比较原声＋两种候选音乐，再比较少量代表镜头的色彩 | 与 A 比较时先保持镜头顺序一致，避免一次改变音乐、顺序、字幕后无法解释差别 |

建议优先 A，是因为现有选段以抚摸、放松和互动为主；这属于画面基础上的判断，不是用户已经选定的账号风格。只有确认声音和完整动作后，才能决定最终方案。

## v01 暴露的问题及下次怎么改

依据本地 [v01 记录](../edits/pet-douyin-v01/README.md) 和用户反馈。这里是差距诊断，不是已经完成的修改。

| 已有情况 | 下一版需要补的工作 | 怎样证明做到了 |
|---|---|---|
| 配乐为程序合成的临时音乐，只确认存在非静音音轨，未实际试听验收 | 先定音乐方向，同一段比较候选；调整音色、节奏、进出点与原声比例 | 试听具体导出版本，记录是否能感知音乐、是否抢戏、是否有突兀循环／收尾 |
| 原对白全部未使用，未完成听辨或转录 | 先审听候选片段，再决定保留哪些对话、动作声或环境声 | 声音清单附源时间码，标明保留／舍弃理由，不能由“降噪”一键决定 |
| 仅做轻微亮度、对比、饱和度调整 | 选本片基准镜头，逐镜匹配，再试整体风格 | 前后对照及相邻镜头连续播放；不以参数变化或加滤镜作为完成证据 |
| 以总览抽帧和候选段细查为主 | 连续观看候选段与导出成片，核对动作、反应、字幕和节奏 | 带时间码的审片记录；抽帧只能证明所见画面，不能证明全片观看 |
| 解码与音量检查曾被用来支撑成片完成度 | 技术检查与视听审片分别写结果 | 没有实际听过就写“试听待验证”；不能从音轨存在推出听感合格 |

## 交付时分清完成阶段

- **粗剪预览：**故事和大致情绪可判断，有可听的原声／临时音乐方案；列出仍待完成的声音、色彩或字幕项。粗剪不是省略情绪设计的理由。
- **精修候选：**镜头、声音、色彩与包装已处理，供比较具体观感；改动说明能对应到时间码。
- **发布候选：**导出文件已完整观看、实际试听，且技术检查通过；音乐、字幕、画面和目标平台版本信息齐全。缺一项就明确对应待验证项，不自动宣称全部完成。

审片主要看六件事：故事是否成立、节奏是否服务动作与情绪、声画是否协调、镜头连接是否自然、颜色与图形是否统一、标题承诺是否兑现。每个不合格项写“时间码＋问题＋修改”，不设置未经校准的“爆款分”。这些提问借鉴并改写自[专业编辑评价 AI 广告的研究](https://arxiv.org/html/2608.24329v1)；该预印本只有 6 位专业剪辑师评价 70 条生成广告，不是宠物题材或传播实验。

本轮没有验证新工具接通、风格效果、观看增长或任何爆款概率；方法是否改善当前作品，需要在下一次精修预览与实际视听中检验。
